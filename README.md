# FitStats - 스마트 피트니스 운동 통계 & SNS 공유 스튜디오

아이폰 건강(Apple Health) 및 구글 핏(Google Fit) 연동을 지원하며, 1일 4대 핵심 지표(운동 횟수, 걸음 수, 소모 칼로리, 최고 심박수)와 월간 운동 통계, 그리고 인스타그램 스토리/피드 전용 고화질 SNS 캡처 카드를 생성하는 모던 웹 애플리케이션입니다.

---

## 🌟 주요 기능

### 1. 1일 핵심 운동 지표 (Daily Performance)
- **1일 운동 횟수**: 하루 동안 완료한 운동 세션 총 개수 및 세션별 타임라인
- **오늘 걸음 수**: 실시간 걸음 수 측정 및 일일 목표(10,000보) 달성률 프로그레스
- **소모 칼로리**: 운동 소모 칼로리 + 활동 대사량 합산 및 불꽃 시각화
- **운동시간 동안 최고 심박수**: 운동 세션 중 측정된 Peak Heart Rate (Max BPM) 및 심박 존(Zone 1~5) 분석
- **하루 심박수 & 운동 피크 SVG 차트**: 24시간 심박수 변화 그래프 및 피크 포인트 마커

### 2. 월간 운동 통계 (Monthly Analytics)
- **월 누적 운동 횟수**: 이번 달 총 완료 세션 수 및 주간 평균 운동 빈도
- **오운완 스탬프 캘린더**: 날짜별 운동 횟수와 달성 뱃지를 달력 히트맵으로 시각화 (날짜 클릭 시 해당 일자로 즉시 이동)
- **종목별 운동 분석**: 러닝, 웨이트 트레이닝, 사이클, 수영, HIIT, 요가 등 종목별 횟수, 시간, 칼로리 분석
- **월간 어슬릿 달성 뱃지**: 오운완 마스터, 만보 클럽, 심폐 강화러 등 동기부여 뱃지

### 3. SNS 캡처 이미지 스튜디오 (Share Studio 📸)
- **SNS 전용 규격 지원**:
  - **인스타그램 스토리 (9:16)**: 스마트폰 풀스크린 규격
  - **인스타그램 피드 (1:1)**: 정방형 피드 규격
  - **블로그 / X (16:9)**: 가로형 와이드 썸네일 규격
- **비주얼 테마**:
  - **네온 사이버 (Neon Cyber)**: 다크 블랙 + 네온 에메랄드/시안 글로우
  - **애플 액티비티 (Apple Activity)**: 레드/그린/블루 피트니스 링 스타일
  - **선셋 글로우 (Sunset Glow)**: 열정적인 오렌지/로즈 일몰 그라디언트
  - **미니멀 다크 (Minimal Dark)**: 심플하고 모던한 블랙 & 실버
- **원클릭 공유 & 연동 액션**:
  - **고화질 PNG 다운로드** (2x 레티나 해상도)
  - **클립보드 이미지 복사** (SNS 글쓰기 창이나 카카오톡에 `Ctrl+V`로 즉시 붙여넣기)
  - **모바일 SNS 시스템 공유** (스마트폰 브라우저에서 인스타그램/카카오톡으로 다이렉트 전송)

### 4. 건강 데이터 연동 (Health Sync)
- **아이폰 건강(Apple Health)**: 아이폰 건강 앱의 `export.xml` 파일 100% 로컬(프라이버시 안전) 파싱 및 아이폰 단축어(Shortcuts) JSON 임포트 지원
- **구글 핏(Google Fit)**: Google Takeout 피트니스 JSON 임포트 지원
- **원클릭 데모 데이터셋**: 계정 설정 없이도 사실적인 35일치 피트니스 데이터 즉시 로드 및 체험

## 🚀 빠른 시작 방법

### Windows 원클릭 실행
`run.bat` 파일을 더블 클릭하면 필요한 패키지 확인 후 개발 서버가 구동되며 기본 웹 브라우저가 자동으로 실행됩니다.

```cmd
run.bat
```

### 수동 실행 (터미널)
```bash
# 1. 의존성 설치
npm install

# 2. 로컬 개발 서버 구동 (http://localhost:3000)
npm run dev

# 3. 단위 테스트 실행 (Vitest)
npm test

# 4. 프로덕션 빌드
npm run build
```
